# content 규칙 (문제 은행·개념 카드·오류 유형 사전)

루트 `AGENTS.md`를 먼저 따른다. 이 폴더의 담당·검수자는 **이동성**이다. 형식은 `docs/01_공통설계.md` 5-6장.

- 파일은 **UTF-8 CSV**, 첫 줄은 열 이름. 엑셀에서 저장할 때는 "CSV UTF-8"을 고른다.
- 쉼표·줄바꿈이 들어간 칸은 큰따옴표로 감싼다.
- 코드(`PHOTO-CHOICE2-007`, `REPLY_NO_EMPATHY`)는 **한 번 정하면 바꾸지 않는다**. 풀이 기록이 코드로 연결된다. 없앨 문제는 지우지 말고 `active`를 `false`로 바꾼다.
- 틀린 보기마다 `error_types.csv`에 있는 오류 유형을 하나씩 붙인다. 없는 코드를 쓰지 않는다.
- 모든 문제에 정답 이유(`explanation`)와 원리 카드(`concept_card_id`)를 붙인다. 규칙형은 근거(연구·플랫폼 가이드), 선호형은 설문 결과가 있어야 한다.
- 이미지는 `content/images/`에 두고 직접 찍었거나 상업적 사용이 허락된 것만 쓴다. 실제 가게·손님 개인정보가 보이면 가린다.
- AI로 문제 변형을 만들 때는 사람이 검수한 뒤에만 `active=true`로 둔다. 검수자 이니셜을 `reviewed_by` 열에 적는다.
- 프로토타입 범위는 PHOTO·REVIEW 두 스킬, 문제 60개 (기획서 12-1).
