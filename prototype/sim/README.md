# 재처방 엔진 시뮬레이터

```bash
npm run sim        # 평가: 가상 사장님 1000명 × 12주, 결과는 sim/results/
npm run sim:tune   # 검증용 무리에서 target·망각 값 고르기
npm test           # 엔진·시뮬레이터 테스트
```

- `world.ts` 가상 사장님 (숨은 의지·여유·바쁜 시간·습관·패턴 변화·이탈)
- 진단 추가 문항 실험: 사장님이 "할 일 하기 어려운 시간"(7일 × 3시간대)을 고르는 상황을 흉내 내요. 일부는 놓치고 일부는 잘못 골라요 (`WORLD.reportHit`, `reportFalse`).
- `policies.ts` 현재 고정 규칙, 고정 규칙 + 질문, v1 칸별 독립 모델, v2 구조화 모델(+ablation), 정답 기준선
- `run.ts` 파일럿(사전분포 학습) → 평가. 같은 사람·같은 운을 모든 정책에 줘요 (common random numbers)
- 엔진 자체는 `lib/engine.ts` (앱에서 그대로 쓸 수 있는 순수 함수)

무리 시드: 파일럿 `seed*1000+1`, 평가 `+2`, 검증 `+3`. 하이퍼파라미터는 검증 무리에서만 골라요.
