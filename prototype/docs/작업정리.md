# 시연 프로토타입 작업 정리 (주승준)

> 2026-11-27 기준. `prototype/` 폴더의 앱을 어떻게 만들었고, 무엇이 되고, 무엇이 남았는지 정리한 문서예요.
> 옮기는 방법은 [`../MIGRATION.md`](../MIGRATION.md), 서버에 기대하는 데이터 모양은 [`api-contract.md`](api-contract.md)를 보세요.

## 1. 한 줄 요약

기획서(`docs/MACO_서비스기획서.md`) 시연 9단계를 **서버 없이 화면만으로 끝까지** 돌려 볼 수 있는 Next.js 앱이에요. 휴대폰·컴퓨터 둘 다 실제 앱처럼 동작하고, 계산 규칙(Elo·XP·관문)은 서버로 옮기기 쉬운 모양으로 `lib/train`에 모아 뒀어요.

## 2. 진행 순서

| 단계 | 한 일 | 결과 |
|---|---|---|
| 1 | 학습 탭 화면 후보 A~E를 만들어 비교 | A안(레슨 경로형) 선택 |
| 2 | A안을 앱에 적용, 같은 와이파이에서 휴대폰으로 열기(`npm run phone`) | 휴대폰에서 직접 사용 |
| 3 | 팀 기획서를 읽고 **기획서대로 다시 만들기** | 탭 5개, 온보딩, 트레이닝 엔진, 시연용 AI |
| 4 | 휴대폰·컴퓨터 화면 맞추기 | 컴퓨터는 왼쪽 메뉴 + 가운데 칸, 휴대폰은 하단 탭 |
| 5 | 휴대폰에서 앱처럼 보이게 | 확대 막기, 홈 화면 추가 시 전체 화면, 320px까지 확인 |
| 6 | 팀 저장소 `prototype/`으로 옮기고 정리 | 예전 루틴 화면 정리, 이전 지도(MIGRATION.md), PR #1 |

기획서로 다시 만들 때 정한 방향:
- **화면 먼저, 서버는 약속만**: 화면은 브라우저 저장소로 돌리고, 서버 모양은 `docs/api-contract.md`로 약속해 둠.
- **시연용 저장 응답으로 먼저**: AI 대신 규칙 채점과 미리 써 둔 응답(`lib/ai/adapter.ts`). 실제 AI는 서버 `AiClient`로.

## 4. 핵심 규칙 (모두 가정값)

| 항목 | 값 | 코드 |
|---|---|---|
| Elo | `p = 1/(1+e^-(θ-d))`, 사용자 K 0.4, 문제 K 0.15, 시작 난이도 Lv1 −1 · Lv3 0 · Lv5 +1 | `lib/train/engine.ts` |
| 다음 문제 | 맞힐 확률 70% 근처 + 복습 예정 +1 + 약점 유형 +0.2 + 집중 레벨 +0.15 − 오늘 본 문제 0.5 | `pickNext` |
| XP | 정답 10 · 오답 2 · 레슨 완료 10 · 쪽지시험 정답 4 + 만점 10 · 틀린 곳 찾기 5 · 유닛 시험 30 · 미션 50 · 7일 연속 20 | `engine.ts` |
| 하루 | 상한 300 XP, 같은 날 같은 문제는 절반, 목표 30/60/120 | `engine.ts` |
| 복습 | 틀리면 다음 날 → 3일 → 7일 | `engine.ts` |
| 약점 | 같은 오류 유형 3번 연속이면 약점 리포트 | `engine.ts` |
| 관문 | 통과 70점, 찾게·믿게 통과 후 광고 열림 | `lib/train/gates.ts` |
| 리그 | 30명, 상위 7 승급, 하위 5 강등 | `lib/train/league.ts` |

## 5. 휴대폰·컴퓨터 화면

- 휴대폰(960px 미만): 하단 탭 5개, 확인·계속·보내기 버튼은 화면 아래에 고정, 입력칸 16px(아이폰 확대 방지), 확대·길게 누르기 메뉴 끔.
- 컴퓨터(960px 이상): 왼쪽 메뉴 + 가운데 720px 칸, 레슨·온보딩은 가운데 좁은 칸, 시작 화면은 두 칸.
- 320·360·375px에서 가로 스크롤 없음 확인. 홈 화면에 추가하면 주소창 없이 열려요(`app/manifest.ts`).

## 6. 확인한 것

- `npx tsc --noEmit`, `npm test`(트레이닝 엔진 12개), `npm run build`, 루트 `node scripts/check-rules.mjs` 통과
- 375px에서 처음부터 끝까지: 시연용 계정 → 온보딩 → 캡처 진단 → 레슨 → 탭 5개 → 4주 넘기기 → 랭킹·QR·상황극
- PR #1 CI 3개 통과

## 7. 아직 남은 것

- 문제 은행 40/60개(사진 20, 리뷰 답글 20). 나머지 4개 유닛은 "준비 중"
- 4주 넘기기 뒤 지역 순위가 기획서 목표(5위)보다 낮게 나옴 → 서버 랭킹에서 다시 맞추기
- P1 기능(친구, 인스타 캡처, 주간 점검) 없음
- 서버 연결 없음: 기록은 그 기기 브라우저에만 저장
- 카카오·네이버 로그인은 키를 넣어야 동작(이름은 `.env.example`)

## 8. 다음에 할 일

`MIGRATION.md` 4장 순서대로, 각자 `feat/<탭>-<내용>` 브랜치에서 담당 부분만 팀 규칙에 맞춰 옮겨요. 서버 API가 생기기 전에는 `src/lib/api/<탭>.ts`에 이 프로토타입 데이터를 돌려주는 가짜 구현(스텁)을 먼저 두면 화면 작업이 막히지 않아요.
