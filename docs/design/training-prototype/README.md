# 트레이닝 탭 디자인 프로토타입 (2026-11-28, 주승준)

S6~S10 트레이닝 탭을 클릭해서 확인하는 **디자인 시안**의 원본 파일이다. 앱 코드가 아니며 `frontend` 빌드에 들어가지 않는다.

- 열어 보기: Claude 디자인 캔버스 <https://claude.ai/artifact/SayLUcLYakgMMbdmYNsHms> (공유받은 사람만 열림)
- `.dc.html` 파일은 캔버스 런타임(`support.js`)에서 돌아간다. 브라우저에서 파일을 바로 열면 화면이 나오지 않는다.
- 화면 구현은 이 시안을 보고 `frontend/src/app/training`, `frontend/src/components/training`에 옮긴다.

## 파일

| 파일 | 내용 |

| `Coach.dc.html` | 고양이 코치 ‘마코’ (기본·정답 귀 쫑긋·오답 메모지 힌트·완료 체크 도장·섹션 완료 축하, 섹션별 도구 8가지) |

| `canvas.json` | 캔버스 보드 배치 |

## 시안에서 정한 것

- 구조: 섹션 7개(사장님이 배우는 것) → 섹션마다 유닛 5개(마케팅 스킬) → 유닛마다 레슨 1개(문제 3개)
- 상단 고정 바: 왼쪽 ‘전체 과정’, 오른쪽 연속학습 / 오늘 XP / 일일 목표 링 → 각각 상세 화면. 뒤로 가면 보던 스크롤 위치로 돌아온다
- 테마: 다크(차콜 `#1d1f23`)가 기본. 상단 바의 ‘다크 모드’ 켜기/끄기 스위치와 ‘내 정보 → 화면 테마’로 라이트(웜그레이 `#f3f1ee`)로 바꾸고, 선택은 유지된다
- 유닛 타일: 완료 = 주황 + 체크(다시 연습 가능), 시작 가능 = 흰색 + 얇은 링 + 재생, 잠김 = 흰색 + 자물쇠. 라이트에서는 흰 타일에 가는 테두리
- 로드맵 기본 화면은 섹션 머리·타일·연결선만. 타일을 누르면 바로 아래 상세 카드(유닛 이름, 배우는 내용, 레슨 시작 / 다시 연습 / 먼저 할 유닛)가 하나만 열린다
- 섹션 머리: 배경보다 밝은 패널(라이트는 섹션 색이 은은한 패널) + 섹션 번호 배지와 왼쪽 띠에 섹션 포인트 색
- 색: 주황(`achieve`)은 완료·진행이 채워질 때만, 보라(`accent`)는 시작 가능 링과 주요 버튼
- 잠금: 이전 유닛을 끝내면 다음 유닛이 열린다. 섹션 마지막 유닛 다음은 다음 섹션 첫 유닛
- 고쳐 쓰기: AI 채점 전에는 준비한 기준 체크 + 예시 답안으로 끝까지 진행
- 움직임: 150~250ms, `prefers-reduced-motion`이면 바로 바뀜

## 실제 구현 때 바꿀 것 (가정값·데모)

- XP 기준(정답 10 · 오답 2 · 레슨 완료 10)과 하루 목표 50 XP는 가정값이다. 서버 `XpService` 응답을 쓴다
- 화면 테마는 시안에서 브라우저 로컬 저장소(`maco-theme-v2`)에 저장한다. 실제 앱은 디자인 토큰(`frontend/src/styles/tokens.css`)에 다크·라이트 두 벌을 두고 같은 방식으로 바꾼다
- 학습 기록은 시안에서 브라우저 로컬 저장소(`maco-training-demo-v2`)에 데모로 저장한다. 실제로는 `/training/path`, `/lessons/sessions/{id}/finish` 응답을 쓴다
- 연속학습 달력(11월 23~29일, 연속 3일)은 데모 데이터다. 날짜는 서버의 `today`를 쓴다
- 섹션·유닛 이름과 문제 105개는 시안용 초안이다. 문제 은행 반영은 이동성(`content/`)과 검수한다
- 샘플 사진은 그림이다. 실제 메뉴 사진으로 바꾼다
