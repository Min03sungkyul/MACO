# 00. 개발 환경 설치 (팀원 전원, 초보자용)

> 목표: **오늘(11/27) 안에 4명 모두 같은 도구를 설치**하고, 마지막의 "설치 확인" 결과를 팀 채팅에 올린다.
> 걸리는 시간: 1시간 30분~2시간 (Docker 설치 때 재부팅 1~2번 포함). 노트북은 **충전기를 꽂고** 시작한다.
> 화면 문구는 프로그램 버전에 따라 조금 다를 수 있다. 모르는 화면이 나오면 기본값(Next)으로 두고 진행한다.

## 먼저 알아 둘 것

- **터미널(PowerShell)**: 명령어를 글자로 입력하는 창이다. 시작 메뉴에서 "PowerShell" 또는 "터미널"을 검색해 연다.
  설치를 하나 끝낼 때마다 **터미널을 닫고 새로 열어야** 새 프로그램이 인식된다.
- **관리자 권한 PowerShell**: 시작 메뉴에서 PowerShell을 **마우스 오른쪽 클릭 → "관리자 권한으로 실행"**. Docker 준비(3단계)에서만 쓴다.
- 이 문서의 회색 상자 안 명령어는 PowerShell에 그대로 붙여 넣고 Enter를 누르면 된다.

## 설치 순서 한눈에 보기

| 순서 | 프로그램 | 왜 필요한가 | 누가 |
|---|---|---|---|
| 1 | Git | 코드 변경 기록·공유 (AI 코딩 도구도 내부에서 사용) | 전원 |
| 2 | GitHub 계정 + GitHub Desktop | 팀 저장소, 버튼으로 Git 사용 | 전원 |
| 3 | WSL2 + Docker Desktop | 모두 같은 MySQL DB를 한 줄로 실행 | 전원 |
| 4 | Node.js (LTS) | 화면(Next.js) 실행 | 전원 |
| 5 | JDK 21 (Temurin) | 서버(Spring Boot) 실행 | 전원 |
| 6 | VS Code | 화면 코드 편집 | 전원 |
| 7 | IntelliJ IDEA | 서버 코드 편집 | 전원 |
| 8 | AI 코딩 도구 | Claude Code (3명) / Codex (1명) | 전원 |
| 나중에 | Postman 또는 Bruno, Figma | API 시험 호출, 화면 디자인 | 필요할 때 |

> 탭 하나를 화면부터 서버까지 맡기 때문에 **프론트·백엔드 상관없이 1~8번을 모두 설치**한다.

---

## 1. Git

1. 브라우저에서 **git-scm.com** → "Download for Windows" → **64-bit Git for Windows Setup** 받기
2. 설치 파일 실행. 대부분 **Next**를 누른다. 아래 두 화면만 확인한다.
   - "Choosing the default editor used by Git": VS Code를 이미 설치했다면 "Use Visual Studio Code", 아니면 그대로 둔다.
   - "Adjusting the name of the initial branch": **"Override the default branch name"을 고르고 `main`** 입력
3. Install → Finish
4. **새 PowerShell**을 열고 확인:

```powershell
git --version
```

`git version 2.xx...`가 나오면 성공.

## 2. GitHub 계정 + GitHub Desktop

1. **github.com**에서 회원가입 (이미 있으면 건너뜀). 아이디는 팀장에게 알려 준다 (저장소 초대에 필요).
2. (권장) **GitHub Education 학생 인증**: education.github.com → 학교 이메일로 신청 → 승인되면 GitHub Pro가 무료. Pro가 있어야 비공개 저장소에서 "main 브랜치 보호"와 "담당자 자동 리뷰 요청"을 쓸 수 있다. 승인까지 며칠 걸릴 수 있으니 오늘 신청만 해 둔다.
3. **desktop.github.com** → GitHub Desktop 받기 → 설치하면 바로 실행된다.
4. **"Sign in to GitHub.com"** → 브라우저에서 로그인 → 허용 → 다시 GitHub Desktop으로
5. "Configure Git" 화면: 이름과 이메일이 GitHub 계정으로 채워진다. 이름은 **본인 한글 이름**으로 바꿔도 된다 (AI 도구가 이 이름으로 담당 영역을 확인한다). Finish.

## 3. WSL2 + Docker Desktop

Docker는 MySQL 같은 프로그램을 "컨테이너"라는 상자에 담아 실행한다. 4명 모두 같은 DB 설정을 명령어 한 줄로 쓰기 위해 필요하다. Windows에서는 WSL2가 먼저 필요하다.

1. **관리자 권한 PowerShell**을 열고:

```powershell
wsl --install
```

2. 설치가 끝나면 **컴퓨터를 재부팅**한다. (이미 설치되어 있다고 나오면 다음으로)
3. 재부팅 후 Ubuntu 창이 뜨면서 사용자 이름·비밀번호를 물으면 영어로 아무거나 정해 입력한다 (비밀번호는 입력해도 화면에 안 보이는 것이 정상). 창은 닫아도 된다.
4. **docker.com/products/docker-desktop** → "Download for Windows – AMD64" 받기
   (CPU가 ARM인 노트북만 ARM64. 대부분은 AMD64)
5. 설치 화면에서 **"Use WSL 2 instead of Hyper-V"가 체크**되어 있는지 확인 → OK → 끝나면 "Close and log out" 또는 재부팅
6. Docker Desktop 실행 → 약관 **Accept** → 로그인 화면은 **Skip**해도 된다. 왼쪽 아래에 초록색 "Engine running"이 보이면 준비 완료.
7. 새 PowerShell에서 확인:

```powershell
docker --version
```

```powershell
docker run hello-world
```

`Hello from Docker!`가 나오면 성공.

> Docker는 컴퓨터를 켤 때마다 **Docker Desktop을 먼저 실행**해야 쓸 수 있다. (설정 → General → "Start Docker Desktop when you sign in"을 켜 두면 편하다)

## 4. Node.js (LTS)

1. **nodejs.org** → 초록색 **LTS** 버튼으로 Windows 설치 파일(.msi) 받기
2. 설치: 모두 Next. "Tools for Native Modules" 체크박스는 **체크하지 않아도 된다**.
3. 새 PowerShell에서 확인:

```powershell
node -v
```

```powershell
npm -v
```

`v24.x` 또는 `v26.x`처럼 버전이 나오면 성공. (짝수 버전이 LTS)

## 5. JDK 21 (Eclipse Temurin)

1. **adoptium.net** → Temurin 다운로드 페이지에서 **버전 21 (LTS)**, Windows, x64, **JDK**, **.msi** 선택해 받기
   (21이 아닌 다른 숫자가 기본으로 보이면 "Other platforms and versions"에서 21을 고른다)
2. 설치 중 **"Custom Setup" 화면이 가장 중요**하다:
   - **"Set JAVA_HOME variable"** 항목 왼쪽 아이콘을 클릭 → **"Will be installed on local hard drive"** 선택 (기본은 꺼져 있다)
   - "Add to PATH"도 켜져 있는지 확인
3. Next → Install → Finish
4. 새 PowerShell에서 확인:

```powershell
java -version
```

```powershell
echo $env:JAVA_HOME
```

첫 줄에 `21.0.x`, 두 번째에 `C:\Program Files\Eclipse Adoptium\jdk-21...` 같은 폴더가 나오면 성공.

## 6. VS Code

1. **code.visualstudio.com** → Windows 버전 받기 → 설치
2. "추가 작업 선택" 화면에서 **"PATH에 추가"**(기본 체크)와 **"Code(으)로 열기 작업을 ... 상황에 맞는 메뉴에 추가"** 두 개를 체크하면 편하다.
3. VS Code 실행 → 왼쪽 네모 4개 아이콘(확장) → 아래를 검색해 설치
   - **Korean Language Pack** (선택, 메뉴 한글화)
   - **ESLint**, **Prettier**, **Tailwind CSS IntelliSense**, **EditorConfig**
4. 확인: 새 PowerShell에서 `code --version`

## 7. IntelliJ IDEA

1. **jetbrains.com/idea/download** → Windows 설치 파일 받기 → 설치
   - 학생은 **jetbrains.com/student**에서 학교 이메일로 신청하면 모든 기능을 무료로 쓸 수 있다. 신청이 늦어지면 무료 버전으로 시작해도 충분하다.
2. 설치 옵션에서 "Add 'bin' folder to the PATH", ".java 연결"은 체크해도 된다.
3. 실행 후 Settings에서 확인 (프로젝트가 생긴 뒤에 해도 된다)
   - Editor → File Encodings → 모두 **UTF-8**
   - Build → Compiler → Annotation Processors → **Enable annotation processing** 체크 (Lombok용)

## 8. AI 코딩 도구

### Claude Code (Claude Pro 사용자 3명)

둘 중 편한 방법 하나. 둘 다 써도 된다.

- **방법 A. Claude 데스크톱 앱** (처음엔 이쪽이 쉬움): **claude.ai/download** → Windows 앱 설치 → Claude Pro 계정으로 로그인 → 위쪽의 **Code** 탭 → 작업 폴더 선택
- **방법 B. 터미널(CLI)**: PowerShell에서

```powershell
irm https://claude.ai/install.ps1 | iex
```

설치 후 **새 PowerShell**에서 `claude`를 입력 → 브라우저에서 Claude Pro 계정으로 로그인.
Claude Code는 Windows에서 **Git(1번)이 먼저 설치되어 있어야** 동작한다.

### Codex (ChatGPT 요금제 사용자 1명)

- **터미널(CLI)**: Node.js(4번)를 설치한 뒤 PowerShell에서

```powershell
npm install -g @openai/codex
```

새 PowerShell에서 `codex` 입력 → **"Sign in with ChatGPT"** → 브라우저에서 로그인.
- VS Code를 주로 쓰면 확장에서 **Codex**(OpenAI 제공)를 설치해도 된다.
- Windows 지원 방식은 자주 바뀌므로, 설치가 안 되면 developers.openai.com/codex 의 Windows 안내를 따른다.

> AI 도구에서 프로젝트를 여는 일(저장소 연결, 규칙 확인)은 [05_단계별_시작가이드.md](05_단계별_시작가이드.md)의 STEP 5에서 한다. 지금은 로그인까지만 하면 된다.

## 막히면 (Windows에서 자주 생기는 일)

| 증상 | 해결 |
|---|---|
| `'git'은(는) ... 인식되지 않습니다` / `node`를 찾을 수 없음 | 터미널을 **닫고 새로** 연다. 그래도 안 되면 컴퓨터 재부팅 |
| `npm` 실행 시 "이 시스템에서 스크립트를 실행할 수 없으므로…" | PowerShell에서 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 실행 → `Y` → 새 터미널 |
| Docker Desktop이 "WSL 2 installation is incomplete" | 관리자 PowerShell에서 `wsl --update` → 재부팅 |
| Docker가 "Virtualization support not detected" | 작업 관리자 → 성능 → CPU → "가상화: 사용"인지 확인. "사용 안 함"이면 BIOS에서 가상화(Intel VT-x / AMD SVM)를 켜야 한다 (노트북 제조사 안내 검색) |
| `java -version`이 21이 아니거나 없음 | JDK 설치를 다시 실행해 "Set JAVA_HOME variable"을 켠다. 다른 Java가 먼저 잡히면 "시스템 환경 변수 편집"에서 Path의 JDK 21 줄을 맨 위로 |
| 한글 폴더 경로에서 이상한 오류 | 저장소는 **영문 경로**(`C:\dev\maco`)에 둔다 (STEP 4) |
| 포트 3306 사용 중 | 예전에 설치한 MySQL을 끄거나(서비스 → MySQL 중지) 팀장에게 알린다 |

에러가 나면 **에러 메시지 전체를 복사해서 AI 도구(Claude/Codex)에 붙여 넣고** "윈도우에서 이 에러를 초보자가 해결하는 방법을 단계별로 알려줘"라고 물어보는 것이 가장 빠르다.
