# MACO 서비스 기획서

Nov 27, 2026 · @Min

MACO는 **매일 10분씩 공부하는 마케팅 트레이닝 앱**입니다. 듀오링고처럼 트레이닝 탭에서 배우고, 시험 탭에서 확인하고, 내 가게 탭에서 적용하고, 랭킹 탭에서 지역·친구와 함께 꾸준히 이어 갑니다. 가게가 없는 입문자는 **학습 모드**에서 연습 가게로, 가게가 있는 사장님은 **내 가게 모드**에서 자기 가게를 배경으로 트레이닝합니다. 대신 해 주지 않고, 혼자서도 하는 사람을 만듭니다.

## 1. 개요

**한 줄 정의: 매일 10분씩 공부하는 마케팅 트레이닝 앱.** 배우고(트레이닝) → 확인하고(시험) → 우리 가게에 적용하고(실전) → 함께 이어 갑니다(랭킹).

### 문제

초보 사장님을 멈추게 하는 것은 돈이나 시간보다 **무엇부터 할지 모름 → 결과를 읽지 못함 → 중단**의 고리입니다.

| 근거 | 수치 |
| --- | --- |
| 온라인 판매 사장님의 1순위 경영 애로 = 마케팅·홍보 (한경협 2025) | 39.2% |
| 디지털·AI 활용 수준이 입문·기초 단계 (중기중앙회 2026) | 83.3% |
| 기업체당 종사자 수, 사장님이 곳 마케터 (중기부 2024) | 1.57명 |
| 결정 직전 지도앱 리뷰·별점을 확인하는 20대 (2026 조사) | 57% |
| 정부 지원사업 참여율 / 미참여 이유 "몰랐다" | 3.2% / 76.2% |

교육은 많지만 실행으로 이어지지 않고, 대행은 비싸고 끊으면 아무것도 남지 않습니다. 플랫폼 AI와 기존 서비스는 모두 "대신 해 주는" 쪽입니다.

### 해결 방향

해외 무작위 실험에서 효과가 확인된 두 가지를 앱으로 옮깁니다.

- **원리 대신 단순한 규칙**으로 가르친다 (Drexler 외 2014)
- **매주 반복 접촉**으로 실행을 이어 간다 (Bruhn 외 2018)

여기에 듀오링고·스픽·포커 트레이닝 앱의 **짧은 매일 연습, 즉시 피드백, 맞춤 난이도, 꾸준함 장치**를 더합니다.

### 목표

| 구분 | 목표 |
| --- | --- |
| 사장님 | 매일 10분 마케팅 트레이닝으로 판단력을 키우고, 우리 가게의 기본기(찾게·믿게·알리게)를 갖춤다 |
| 서비스 성공 지표 (North Star) | 주간 트레이닝 지속률(일일 목표 달성 일수) + 실전 미션 완료율 |
| 12/16 발표 | 훈련 → 난이도 조절 → 실전 미션 → 성장 흐름을 시연 |

기존 소논문의 BCT 6단계 코칭(진단 → 처방 → 실행 → 기록 → 피드백 → 재처방)을 실전 루프로 이어받습니다.

## 2. 포지셔닝

&#91;embedded content: 포지셔닝 · 가게 단계 × 지원 방식\]

대행사·플랫폼 AI·선배 작품 PULSE는 모두 대신 해 주는 쪽이고, 교육은 실행까지 함께하지 않습니다. MACO는 막 시작한 가게 사장님이 스스로 하게 만드는 빈자리에 섭니다.

| 구분 | PULSE (선행 작품) | MACO |
| --- | --- | --- |
| 정체성 | 리뷰 분석과 콘텐츠 생성 도구 | 매일 10분씩 공부하는 마케팅 트레이닝 앱 |
| 대상 | 리뷰가 쌓인 외식업 가게 | 리뷰 0\~20개의 초기 매장형 가게 |
| AI의 역할 | 대신 만듦 (영상·답글) | 채점하고 가르침 (첨삭) |
| 사용 패턴 | 필요할 때 분석 | 매일 10분 트레이닝·시험, 리그로 계속 |
| 성장하는 것 | 가게의 콘텐츠 | 사장님의 실력과 가게의 기본기 |
| 데이터 | 리뷰 자동 수집 | 사장님이 올린 캡처 + 공식 API |

PULSE 발표가 스스로 밝힌 약점(리뷰가 적은 매장의 데이터 공백, 매출 효과 미검증, 리뷰 수집 약관 위험)이 MACO가 서는 자리입니다.

## 3. 핵심 원칙과 대상

모든 기능은 **대신 해 주지 않는다**는 원칙을 지킵니다. AI는 결과물을 만들지 않고, 사장님이 만든 것을 채점하고 가르칩니다.

| 원칙 | 질문 | MACO의 답 | 근거 |
| --- | --- | --- | --- |
| ① 순서 | 무엇부터? | 3관문: 찾게 → 믿게 → 알리게. 앞 관문을 통과해야 광고가 열림 | 가용성 이론, 리뷰 인과 연구 (Luca, Anderson & Magruder) |
| ② 습관 | 어떻게 꾸준히? | 매일 10분 일일 목표, XP·스트릭·리그, 습관 고리, 바쁜 날 2분 복습, 다시 시작 규칙 | BCT Taxonomy v1, 기존 소논문 |
| ③ 역량 이전 | 어떻게 스스로? | 맞춤 난이도 훈련 + AI 첨삭. 실행은 사장님이 직접 | 의도적 연습 (Ericsson 1993), 자동화 수준 (Parasuraman 2000) |
| ④ 정직한 판정 | 효과가 있었나? | 기록으로 판정, 결과는 확률로, 광고 효과를 과장하지 않음 | Lewis & Rao 2015 |

**트레이닝 모델: 배우기 → 시험 → 적용 → 함께 이어 가기.** 탭 네 개가 이 네 단계에 하나씩 대응합니다(9장). 새 개념은 트레이닝 탭에서 개념 카드와 연습 문제로 배우고, 시험 탭의 쪽지시험·상황극으로 확인하고, 내 가게 탭에서 실제로 적용하고, 랭킹 탭의 리그·지역 순위로 꾸준함을 이어 갑니다.

### 대상 사용자

| 구분 | 대상 |
| --- | --- |
| 주 대상 | 오픈 초기(리뷰 0\~20개)의 매장형 동네 가게 사장님 (카페, 식당, 뷰티, 공방) |
| 확장 대상 | 예비 창업자, 마케팅 입문자 (훈련 루프만 사용) |
| 시연 | 오픈 3개월째 동네 카페 사장님 (리뷰 3개) |

**대표 페르소나**: 오픈 3개월째 카페를 혼자 운영하는 30대 사장님. 마감 후 휴대폰을 보지만 "뭘 올려야 할지, 광고를 해야 할지" 모릅니다. 대행사 전화를 받아 봤지만 믿지 못했고, 하루에 쓸 수 있는 시간은 10분 안팎입니다.

### 3-1. 두 가지 사용 모드

같은 훈련 엔진을 쓰되, **문제의 배경**이 다릅니다. 가게가 없는 사람은 연습 가게로, 가게가 있는 사람은 자기 가게로 배웁니다.

| 구분 | 학습 모드 (입문자) | 내 가게 모드 (사장님) |
| --- | --- | --- |
| 대상 | 예비 창업자, 마케팅 입문자, 사업자 등록 전 | 가게를 운영 중인 사장님 (리뷰 0\~20개 초기 가게 중심) |
| 시작 | 관심 업종 선택 → 배치 테스트 | 가게 등록 → 배치 테스트 → 캡처 진단 |
| 연습 배경 | **연습 가게**: 업종별 가상 가게(예시 플레이스·인스타 화면, 메뉴, 리뷰) | **내 가게**: 실제 화면 캡처, 메뉴, 리뷰 |
| 문제 구성 | 공통 코어 + 업종 팩 (문제 은행 100%) | 공통 코어 + 내 가게 맞춤 문제 (약 6:4, 가정값) |
| 상황극 | 연습 가게의 가상 손님 | 내 가게 업종·메뉴로 만든 가상 손님 |
| 실전 미션 | 연습 가게 미션 (제출·첨삭만) | 내 가게 미션 (실행·첨삭·관문 재진단) |
| 성장 지표 | 실력 점수, 스킬 레벨 | 실력 점수 + 관문 점수 |

**문제를 나누는 규칙**

- **공통 코어**: 두 모드가 같이 푸는 규칙형·선호형 문제 (예: 가격이 빠진 문구 찾기)
- **업종 팩**: 학습 모드에서 고른 업종의 연습 가게 문제 (MVP는 카페 1개)
- **내 가게 맞춤 문제**: 문제 틀에 내 가게 정보와 캡처 진단에서 나온 약점을 채워 출제 (예: "우리 가게 플레이스에서 손님이 떠나는 곳 찾기")
- **모드 전환**: 창업하면 내 가게 모드로 바꿀 수 있고, 실력 점수와 레벨은 그대로 이어집니다.

## 4. 서비스 구조

MACO는 두 개의 루프로 움직입니다. 마케팅은 진짜 결과(손님·매출)가 느리고 운이 섞이므로, 즉시 채점되는 훈련과 우리 가게에 적용하는 실전을 나눕니다.

&#91;embedded content: 서비스 구조 · 훈련 루프와 실전 루프\]

트레이닝 루프(트레이닝 탭·시험 탭)는 매일 10분 돌고, 스킬 레벨이 오르면 실전 미션이 열립니다. 실전 루프는 기존 소논문의 BCT 6단계(진단→처방→실행→기록→피드백→재처방)를 그대로 따르고, 관문 재진단 결과는 다음 훈련의 약점·문제 선택에 반영됩니다.

## 5. 커리큘럼

MACO는 마케팅 전체가 아니라 **동네 가게 사장님이 매주 반복하는 마케팅 행동**만 가르칩니다. 우선순위는 빈도 × 영향 × 초보자 실수율로 정하고, 목차는 3관문 순서를 따릅니다. 듀오링고가 CEFR로 언어를 나눠듯, 레벨마다 할 수 있다 문장으로 정의합니다.

| 유닛 | 관문 | Lv1 | Lv3 | Lv5 |
| --- | --- | --- | --- | --- |
| 1. 기본 정보 | 찾게 | 플레이스 필수 항목을 빠짐없이 채울 수 있다 | 휴무·변경 공지를 제때 올릴 수 있다 | 손님이 검색할 키워드를 고를 수 있다 |
| 2. 보여 주기 (사진) | 찾게 | 밝기·흔들림으로 나쁜 사진을 골라낼 수 있다 | 구도와 주인공이 살아 있는 사진을 고를 수 있다 | 대표 사진 순서를 손님 입장에서 짤 수 있다 |
| 3. 리뷰 | 믿게 | 답글이 필요한 리뷰를 고를 수 있다 | 칭찬 리뷰에 따뜻하게 답할 수 있다 | 불만 리뷰에 공감·사과·개선으로 답할 수 있다 |
| 4. 소개 문구 | 믿게 | 가격·위치가 빠진 문구를 찾을 수 있다 | 혜택과 행동 유도를 넣을 수 있다 | 손님 상황에 맞는 문구를 쓸 수 있다 |
| 5. 알리기 | 알리게 | 소식·쿠폰의 쓰임을 안다 | 손님이 가게를 떠올리는 순간을 찾을 수 있다 | 우리 가게에 맞는 채널을 고를 수 있다 |
| 6. 광고와 숫자 | 알리게 | 조회·저장·길찾기의 차이를 안다 | 광고를 켜도 되는지 판단할 수 있다 | 예산·중지 기준을 정하고 결과를 확률로 읽을 수 있다 |

Lv2·Lv4는 앞뒤 레벨의 중간 난이도로, 전문가 검토 때 채웁니다.

### 정답이 있는 것만 훈련으로, 없는 것은 코칭으로

| 종류 | 예 | 정답 방식 | 다루는 곳 |
| --- | --- | --- | --- |
| 규칙형 | 필수 정보, 가격 표기, 답글 원칙, 광고 판단 | 연구·플랫폼 가이드 기반 규칙 | 훈련 루프 |
| 선호형 | 어느 사진·문구가 더 끌리나 | 설문으로 모은 손님 다수의 선택 | 훈련 루프 |
| 상황형 | 우리 가게만의 강점, 우리 동네 손님 | 정답 없음 | 실전 루프 (미션 + 첨삭) |

### 교재 재료와 검증

- 재료: 네이버 스마트플레이스·인스타그램 비즈니스 공식 가이드, 소상공인시장진흥공단 교육 과정, 리뷰·광고 측정 연구, 가용성 이론
- 도출 절차: 기존 소논문과 같은 요구사항 → 참조 → 선별·변환 → 구조화
- 검증: 마케팅 실무자·교수 3\~5명의 델파이 합의
- 업종: 공통 코어 + 업종 팩 (MVP는 공통 코어 + 카페 팩)

## 6. 사용자 흐름

&#91;embedded content: 사용자 흐름 · 처음 한 번, 매일, 매주\]

처음 한 번은 가입, 배치 테스트, 관문 진단, 목표 설정을 합니다. 그 뒤로는 매일 10분(레슨 + 쪽지시험)이 반복되고, 레벨이 오르면 매주 실전 미션이 열립니다. 주간 체크인에서 믿게 관문을 통과하면 광고 관문이 풀립니다.

**바쁜 날**: 레슨 대신 1문제만 풀어도 스트릭이 유지되고, 2일 이상 쉬면 다시 시작 제안이 나옵니다.

## 7. 기능 명세

기능은 다섯 묶음입니다. 우선순위 P0은 12/16 시연에 반드시 들어가고, P1은 여유가 있으면, P2는 발표 뒤입니다.

## 8. 훈련 엔진 기능 흐름도

&#91;embedded content: 훈련 엔진 · 출제부터 다음 문제까지\]

고르기·찾기·상황 판단 문제는 문제 은행의 정답으로 규칙 채점하고, 고쳐 쓰기만 AI가 채점합니다. 채점이 끝나면 사장님의 스킬 실력과 문제 난이도가 동시에 갱신되고, 틀린 유형은 약점으로 기록되어 복습 시점이 예약됩니다.

**실력·난이도 갱신식** (Elo 방식, θ = 사장님 실력, d = 문제 난이도, r = 정답이면 1, 오답이면 0, K = 변화 폭):

```latex
p = \frac{1}{1 + e^{-(\theta - d)}}, \quad \theta \leftarrow \theta + K(r - p), \quad d \leftarrow d - K(r - p)
```

다음 문제는 맞힐 확률 p가 70% 근처인 문제 중에서, 약점 스킬과 복습 예정 문제를 먼저 고릅니다. 너무 쉽지도 어렵지도 않은 문제가 나오는 이유입니다.

## 8-1. 내 가게 진단 → 상황극·게임

**검토 결과: 넣는 것을 추천합니다.** 캡처 진단이 끝이 아니라 **연습의 시작점**이 되면, 훈련 루프와 실전 루프를 잇는 다리가 됩니다. PULSE는 리뷰를 분석해 결과물을 만들어 주고, MACO는 진단에서 나온 약점을 사장님이 직접 연습하게 합니다. 시연 임팩트와 재미도 가장 크게 더해 줍니다.

### 흐름

1. **캡처 업로드**: 네이버 플레이스(홈·리뷰 탭), 인스타그램(프로필·피드). 학습 모드는 연습 가게의 예시 캡처 사용
2. **AI가 항목 읽기** → 사장님이 확인·수정
3. **규칙 평가**: 관문별 점수 + 항목별 진단 카드 ("메뉴 가격 없음", "답글률 20%", "최근 30일 게시 0건")
4. **약점에 맞춘 연습 자동 배정**: 내 화면 틀린 곳 찾기, 상황극, 퀘스트

| 플랫폼 | 읽는 항목 | 관문 |
| --- | --- | --- |
| 네이버 플레이스 | 영업시간, 메뉴·가격, 사진 수, 리뷰 수, 별점, 최근 리뷰 날짜, 사장님 답글, 소식·쿠폰 | 찾게·믿게 |
| 인스타그램 | 프로필 소개·위치·연락처·링크, 게시물 수, 최근 게시일, 하이라이트 (팔로워 수는 참고만) | 알리게 |

- **비용 관리**: 상황극은 3턴까지, 루브릭 채점, 시연은 저장된 응답 사용

## 8-2. 점수 체계·리그·지역 랭킹

듀오링고·포커 트레이닝 앱처럼 모든 트레이닝 활동에 점수(XP)를 주고, 하루 트레이닝량인 **일일 목표**와 주간 순위인 **리그·지역 랭킹**으로 꾸준함을 만듭니다. 아래 숫자는 모두 출발 가정값이며 사용자 평가 뒤 조정합니다.

### XP 배점

| 활동 | XP |
| --- | --- |
| 연습 문제 | 정답 10, 오답 2 (시도 점수) |
| 레슨 완료 | +10 |
| 쪽지시험 | 정답당 4, 만점 보너스 +10 |
| 상황극 | 루브릭 점수 0\~100을 0\~20 XP로 환산 |
| 내 화면 틀린 곳 찾기 | 찾을 때마다 5 |
| 유닛 시험 통과 | 30 |
| 실전 미션 완료 (첨삭 통과) | 50 |
| 7일 연속 트레이닝 | +20 |

- **일일 목표**: 가볍게 30 / **기본 60 (약 10분: 레슨 1개 + 쪽지시험)** / 열심히 120 XP
- **점수 부풀리기 방지**: 같은 문제를 반복하면 XP 감소, 하루 XP 상한(예: 300), 실전 미션은 첨삭을 통과해야 인정

### 주간 리그

- 일일 목표를 한 번이라도 채우면 그 주 리그에 참가, 주간 XP가 비슷한 30명이 한 그룹
- 등급 5단계(이름은 가정): 동네 새싹 → 골목 스타 → 상권 고수 → 지역 명소 → 마케팅 마스터
- 매주 월요일 초기화, 상위 7명 승급·하위 5명 강등

### 지역 랭킹

- 구 단위 주간 XP 순위: "인천 부평구 23위 / 412명 (상위 6%)"
- 지역 기준: 내 가게 모드는 등록한 매장 주소의 구, 학습 모드는 관심 지역을 직접 선택
- 화면에는 내 순위, 상위 10명, 바로 위·아래 순위만 표시 (하위권 전체는 공개하지 않음)

### 친구·인증 매장·협업 (향후 확장)

- **친구**: 초대 코드·QR로 추가, 친구 랭킹, 응원 보내기
- **실제 매장 인증 마크**: 사업자등록 진위 확인(국세청 공공 API) + 가게 정보 일치 시 인증 배지. 인증 매장은 랭킹에 매장명 표시 선택 가능
- **협업 신청 → 제휴 매장**: 같은 동네의 다른 업종 인증 매장끼리(예: 카페 + 베이커리) 공동 쿠폰·상호 홍보를 제안

### 근거와 주의

- 기존 소논문은 순위 비교를 제외했습니다. 보상·순위만 준 걷기 앱은 걸음 수 변화가 거의 없었기 때문입니다 (김유진·정경미 2020). 반면 리더보드가 학습 시간을 늘렸다는 연구도 있고 (Landers & Landers 2014), 게이미피케이션 효과는 맥락에 따라 다릅니다 (Hamari 외 2014). 원문 확인 후 인용합니다.
- 그래서 **주 동기 장치는 일일 목표와 스트릭**, 리그는 **보조 장치**로 둡니다. 비슷한 레벨끼리만 경쟁하고, 하위권은 공개하지 않으며, 끌 수 있습니다.
- **연구 기회**: 사용자 평가에서 리그를 켠 집단과 끈 집단의 7일 트레이닝 지속을 비교하면, 소논문의 순위 제외 결정을 직접 검증할 수 있습니다.

## 8-3. MACO AI 튜터 시스템

MACO의 모든 탭 뒤에는 **MACO AI 튜터** 하나가 있습니다. 튜터는 사람마다 무엇을 배울지, 얼마나 어렵게 할지, 어떻게 코칭할지를 정합니다. 트레이닝 탭은 **듀오링고의 학습 설계**를, 시험 탭은 **스픽의 AI 튜터**를 벤치마킹합니다. 원칙은 기존과 같습니다. 판단은 설명 가능한 규칙·통계가 하고, 말은 AI가 합니다.

&#91;embedded content: MACO AI 튜터 구조 · 학습자 모델, 튜터 엔진, AI 튜터, 콘텐츠 지도\]

### 튜터의 네 구성 요소

| 구성 | 하는 일 | 구현 |
| --- | --- | --- |
| 학습자 모델 | 사람마다 스킬별 실력(Elo), 오류 유형별 약점, 복습 시점, 트레이닝 습관(시간대·지속), 가게 맥락(업종·관문 점수)을 저장 | DB + 규칙·통계 |
| 튜터 엔진 | 오늘 할 일(레슨·복습·쪽지시험·상황극·미션), 난이도(맞힐 확률 약 70%), 코칭 메시지를 결정 | 규칙표 + Elo |
| AI 튜터 | 오답 설명, 상황극 대화, 교정과 더 나은 표현, 레슨·대화 후 요약, 주간 코칭 카드 문장 | LLM, 형식 검사, 실패 시 규칙 문장 |
| 콘텐츠 지도 | 스킬 트리, 문제 은행, **오류 유형 사전**(가격 누락, 행동 유도 없음, 공감 없음 등), 근거 카드 | DB (팀이 작성·검수) |

**개인화의 열쇠는 오류 유형 사전**입니다. 레슨 문제, 쪽지시험, 상황극 채점, 실전 첨삭이 모두 같은 오류 유형으로 태그됩니다. 그래서 어디서 틀리든 약점이 학습자 모델 한 곳에 모이고, 튜터가 그 약점으로 다음 레슨·복습·코칭을 정합니다.

### 듀오링고에서 가져올 것 → 트레이닝 탭

| 듀오링고 | 원리 | MACO 적용 | 우선 |
| --- | --- | --- | --- |
| 학습 경로(유닛·섹션) | 순서가 정해진 짧은 단계 | 유닛 6개 경로, 3관문 순서 | P0 |
| 다양한 문제 유형 | 같은 개념을 여러 방식으로 | 둘 중 고르기·틀린 곳 찾기·고쳐 쓰기·상황 판단 | P0 |
| 개인화 엔진(Birdbrain, 맞힐 확률 예측) | 너무 쉽지도 어렵지도 않게 | Elo 실력·난이도, 맞힐 확률 70% 근처 출제 | P0 |
| Explain My Answer | 내 오답에 맞춰 AI가 이유 설명 | "왜 틀렸어요?" 버튼 → AI 튜터가 오류 유형에 맞춰 설명 | P0 |
| 간격 반복 | 잊을 때쯤 다시 | 복습 예약 | P1 |
| 연습 허브(Practice Hub) | 내 실수만 모아 연습 | 약점 연습 (오답 노트와 연결) | P1 |
| 스트릭·XP·일일 목표·리그 | 습관과 동기 | 8-2 | P0 |
| 일일 퀘스트 | 작은 목표 여러 개 | 오늘의 퀘스트 3개 (예: 쪽지시험 80점 이상) | P1 |

**가져오지 않을 것**: 하트(틀리면 진행이 막힘)는 초보자를 멈추게 해서 지속 원칙과 충돌합니다. 압박형 알림도 쓰지 않습니다.

### 스픽에서 가져올 것 → 시험 탭 (AI 튜터)

| 스픽 | 원리 | MACO 적용 | 우선 |
| --- | --- | --- | --- |
| AI 튜터 대화·롤플레이 | 실제 상황에서 직접 말해 보기 | 상황극: AI 손님(불만 리뷰, 메뉴 문의, 단골)과 대화 | P0 |
| 대화 중 피드백 | 그 자리에서 교정 | 턴마다 "더 좋은 표현 보기" 힌트 (누를 때만) | P1 |
| 대화 후 피드백 | 잘한 점, 고칠 점, 더 나은 문장 | 상황극 리포트: 루브릭 점수 + 고칠 문장 3개 + 다시 하기 | P0 |
| 개인화 복습 | 내 실수로 만든 복습 | 상황극·첨삭의 오류 → 다음 쪽지시험 문제 | P0 |
| 맞춤 상황 | 내 상황으로 연습 | 내 가게 상황극 (내 업종·메뉴·자주 받는 리뷰 유형) | P1 |
| 튜터 통화(짧은 1:1 세션) | 정기 점검 | 주간 코칭 세션: 튜터가 한 주를 돌아보고 다음 주 계획 제안 (텍스트 대화 5분) | P1 |

발음 피드백은 가져오지 않습니다. 마케팅 트레이닝은 글과 판단이 중심입니다.

### 튜터가 사람마다 다르게 하는 일 (개인별 코칭 규칙)

| 상황 | 튜터의 행동 | 근거 |
| --- | --- | --- |
| 가격 정보를 3번 빠뜨림 | 다음 레슨에 가격 문제 2개 추가, 쪽지시험에 포함, 30초 근거 카드 | 약점 집중 (의도적 연습) |
| 이틀 쉼 | "오늘은 2분만" 복습 제안 | BCT 다시 시작 |
| 상황극 공감 점수가 낮음 | 같은 유형 상황극을 힌트와 함께 다시 배정 | 개인화 복습 |
| 내 가게 답글률 20% | 리뷰 답글 유닛을 앞으로, 실전 미션 연결 | 3관문 순서 |
| 일주일 목표 100% | 난이도·목표 한 단계 상향 제안 (수락해야 적용) | 수정 가능한 추천 |
| 주말마다 쉼 | 주말 목표를 가볍게로 제안 | 습관 맞춤 |

- 규칙은 규칙표로 정하고, 문장만 AI가 씁니다.
- **튜터 메모리**: 지난 세션의 약점과 약속을 기억해 이어서 말합니다. ("지난주에 말한 가격 표기, 이번엔 잘했어요")
- **튜터 성격**: 이름은 마코 코치, 존댓말, 짧고 친근하게, 잘한 점 먼저·고칠 점은 하나만
- **안전·비용**: AI 응답은 형식 검사, 실패하면 규칙 문장으로 대체. 설명은 버튼을 누를 때만, 상황극은 턴 수 제한, 같은 입력은 결과 재사용

### 연구 기여

규칙 기반 튜터 엔진(판단, 설명 가능)과 LLM 튜터(설명·대화)를 나눈 **하이브리드 AI 튜터 구조**, 그리고 **오류 유형 사전 기반 개인화**는 기존 소논문의 BCT 프레임워크를 잇는 후속 연구 주제가 됩니다.

## 9. 탭 구성과 화면

모바일 웹 우선이고, 하단 탭은 **5개**입니다. 듀오링고가 학습과 연습을 나누듯, 탭마다 하는 일이 겹치지 않게 나눠습니다: **트레이닝 탭은 새로 배우기, 시험 탭은 확인하고 굳히기, 내 가게 탭은 실제로 적용하기, 랭킹 탭은 함께 이어 가기, 내 정보 탭은 성장 확인하기**.

## 10. 기술 구조와 AI 활용

핵심은 **규칙 엔진과 문제 은행**이고, AI는 첨삭과 캡처 읽기에만 필요할 때 씁니다.

| 계층 | 기술 | 역할 |
| --- | --- | --- |

| ai\_log, ai\_cache | AI 사용량, 같은 입력 결과 재사용 |

점수·랭킹용 추가 테이블: **xp\_log**(활동별 XP·시각), **daily\_goal**(목표·달성 여부·트레이닝 시간), **league\_group**(주차·등급·구성원), **region**(시·구 코드, 주간 지역 순위는 집계 쿼리), **friend**(친구 관계), **quiz\_attempt**(쪽지시험 점수).

### AI 사용처와 비용 원칙

| 사용처 | 종류 | 호출 시점 |
| --- | --- | --- |
| 고쳐 쓰기 채점 (B4) | 텍스트 | 사용자가 제출할 때 |
| 미션 첨삭 (D2) | 텍스트·이미지 | 제출할 때 |
| 관문 진단 캡처 읽기 (A4, D4) | 이미지 | 캡처를 올릴 때 |
| 문제 변형 만들기 (E5) | 텍스트 | 개발 단계에서 한 번 (사람이 검수) |

AI 튜터(8-3)의 추가 사용처: 오답 설명("왜 틀렸어요?" 버튼을 누를 때만), 상황극 대화와 대화 후 피드백, 주간 코칭 세션의 문장. 다음 할 일·난이도·코칭 판단은 튜터 엔진(규칙·Elo)이 하므로 AI 비용이 들지 않습니다.

- 레슨의 출제·채점·난이도는 규칙과 문제 은행이 하므로 **매일 훈련에는 AI 비용이 들지 않습니다.**
- AI 결과는 JSON 형식으로 받아 검사하고, 실패하면 미리 쓴 체크리스트로 대체합니다.
- 모델은 D7 비교 테스트(한국어 첨삭 품질, 캡처 숫자 읽기 정확도, 비용)로 정합니다.

## 11. 연구·검증 계획

연구 질문은 하나입니다: **맞춤 난이도 훈련과 실전 코칭을 결합하면 초보 사장님의 마케팅 판단력과 실행 지속이 나아지는가.**

### 이론적 뼈대 (원문 확인 후 인용)

| 층 | 이론·연구 | MACO에서의 역할 |
| --- | --- | --- |
| 행동 | BCT Taxonomy v1 (Michie 외 2013), 기존 소논문 | 습관·지속, 실전 루프 |
| 학습 | 의도적 연습 (Ericsson 외 1993), 간격 복습 (Settles & Meeder 2016) | 매일 훈련, 복습 |
| 적응형 난이도 | Elo 레이팅의 교육 적용 (Pelánek 2016), 수학 학습 앱 (Klinkenberg 외 2011) | 실력·난이도 점수 |
| 순서 | 가용성 이론, 리뷰 인과 연구 (Luca, Anderson & Magruder, Proserpio & Zervas) | 3관문, 커리큘럼 목차 |
| 교육 효과 | 규칙 교육 (Drexler 외 2014), 반복 컨설팅 (Bruhn 외 2018) | 규칙형 문제, 매주 접촉 |
| 자동화·신뢰 | 자동화 수준 (Parasuraman 외 2000), 수정 가능한 추천 (Dietvorst 외 2018) | AI는 첨삭, 실행은 사장님 |
| 측정 | Lewis & Rao 2015 | 확률 판정 |

추가 층 **게이미피케이션**: 게이미피케이션 메타 연구 (Hamari 외 2014), 리더보드와 학습 시간 (Landers & Landers 2014), 보상·순위의 한계 (김유진·정경미 2020) → XP·일일 목표·리그 설계 (8-2).

### 검증 단계

1. **커리큘럼 타당도 (델파이)**: 마케팅 실무자·교수 3\~5명이 유닛·레벨의 중요도를 2회 평가해 합의
2. **선호형 정답 데이터**: 카페 사진·문구 쌍 30개를 학생·지역 주민 50\~100명에게 보여 "어느 쪽에 더 가고 싶나" 설문 → 문제 정답으로 사용
3. **사용자 평가**: 사장님·예비 창업자 5\~8명이 배치 테스트 → 레슨 → 재테스트. 정답률 변화, 기술 수용 모델(TAM) 문항, 지불 의향(반 베스텐도르프) 측정
4. **(발표 뒤) 파일럿**: 신규 가게 1\~3곳, 4주. 훈련 지속률, 미션 완료율, 관문 점수 변화

사용자 평가에서는 리그를 켠 집단과 끈 집단의 **7일 트레이닝 지속**도 비교합니다(일일 목표 달성 일수 기준). 기존 소논문의 순위 제외 결정을 직접 검증하는 부분입니다.

표본이 작으므로 결과는 기술통계로만 보고하고, 매출 효과는 주장하지 않습니다.

## 12. 시연 시나리오 (3분)

메시지는 하나입니다: **MACO는 대신 해 주지 않고, 매일 10분 마케팅 트레이닝으로 혼자서도 하는 사람을 만듭니다.**

1. **두 사용자 소개**: 가게가 없는 예비 창업자와 리뷰 3개뿐인 부평구 카페 사장님. "둘 다 마케팅을 어디서부터 시작해야 할지 모릅니다"
2. **트레이닝 탭 (학습 모드)**: 연습 가게로 개념 카드 → 둘 중 고르기 오답 → 원리 카드 → 다음 문제 난이도 조절 → XP와 일일 목표 링
3. **시험 탭**: 오늘의 쪽지시험 5문제 → 80점, 오답 노트에 들어간 문제 확인
4. **내 가게 탭 (사장님 모드)**: 플레이스·인스타 캡처 → 찾게 주의, 믿게 미통과, 광고 자물쇠 → 내 화면 틀린 곳 찾기
5. **상황극**: 불만 리뷰 AI 손님과 3턴 대화 → 루브릭 점수와 XP
6. **랭킹 탭**: "이번 주 부평구 23위 / 412명", 주간 리그 승급선까지 30 XP
7. **실전 미션**: 리뷰 요청 QR 카드 출력, 실제 카드를 무대에서 보여 줌
8. **4주 넘기기**: 스트릭 28일, 지역 5위, 다시 캡처 → 믿게 통과, 광고 자물쇠 해제 → 내 정보 탭 성장 리포트
9. **마무리**: 선행 작품 PULSE와의 자리 비교 한 장, "매일 10분 마케팅 트레이닝"

시연 계정의 AI 응답은 미리 저장해 두어 인터넷이 느려도 멈추지 않게 합니다.
