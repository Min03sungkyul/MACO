# 팀원 PR 리뷰

> 팀원(주승준·박민하·이동성)의 PR은 팀장 강민국이 리뷰·승인한다. 강민국 본인의 PR은 리뷰 없이 병합할 수 있다.

1. PR 브랜치를 받는다: `git fetch` → `git switch <브랜치>` (GitHub Desktop: Current branch에서 선택).
2. 변경 내용을 읽는다: `git diff main...HEAD`.
3. 확인할 것 (중요한 순서)
   - **동작**: 버그, 빠진 예외 처리, 로그인 없이 다른 사람 데이터에 접근할 수 있는지
   - **공통 규칙** (`AGENTS.md` 4장): AppClock, AiClient, XpService, SkillService, 마이그레이션, 비밀값, 패키지 경계
   - **시연 영향**: 기획서 12장 시연 9단계 중 어느 장면에 영향이 있는지, 깨지는 곳이 없는지
   - **API 맞춤**: 서버 DTO, `docs/03`, `lib/types`가 같은지
   - **화면**: 로딩·에러·빈 상태, 375px
4. 직접 실행해 본다: 검사 명령어 + 해당 화면 한 번 사용.
5. 의견을 정리한다: "꼭 고칠 것 / 고치면 좋은 것 / 질문" 세 묶음으로, 파일과 줄을 적어 짧게.
6. 리뷰 의견을 GitHub에 올리는 것은 사용자가 직접 하거나, 사용자가 요청할 때만 한다.
