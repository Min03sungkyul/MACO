# AI 기능(AiTask) 추가

AI 모듈 담당은 강민국. 다른 담당자는 AiTask를 **요청**하고, 직접 `ai` 패키지를 고치지 않는다.

1. **정말 AI가 필요한가**: 출제·채점·난이도·코칭 판단은 규칙으로 한다. AI는 문장 첨삭·오답 설명·상황극 대화·캡처 읽기에만 쓴다. 규칙으로 되면 AI를 쓰지 않는다.
2. **AiTask 등록**: `com.maco.ai.AiTask`에 이름 추가.
3. **입력·출력 타입**: `record`로 정의. 출력은 반드시 JSON으로 받을 수 있는 구조.
4. **프롬프트 파일**: `backend/src/main/resources/prompts/<task>.md`. 들어갈 것: 역할(코치·첨삭자, 대신 써 주지 않음), 입력 설명, 출력 JSON 예시, 금지 사항(사용자 이름·연락처 사용 금지, 효과 과장 금지). 한국어 존댓말.
5. **형식 검사**: 받은 JSON을 출력 타입으로 바꿔 보고, 실패하면 1번만 다시 요청한다.
6. **대체 결과(FALLBACK)**: 두 번 실패하거나 `AI_MODE=off`이면 돌려줄 규칙 문장·체크리스트를 만든다 (`error_types.csv`의 `fix_tip` 활용).
7. **캐시·기록**: 같은 입력은 `ai_cache`에서 꺼낸다. 모든 호출은 `ai_log`에 모델·토큰·비용·시간을 남긴다.
8. **시연 저장 응답**: 시연 입력에 대한 응답을 `ai_recorded`에 넣어 `AI_MODE=recorded`에서 동작하게 한다.
9. **테스트**: 실제 API를 부르지 않는다. 형식 검사 실패 → FALLBACK 흐름을 목(mock)으로 테스트한다.
10. **비용 메모**: 한 번 호출에 드는 대략의 토큰과 하루 예상 호출 수를 PR에 적는다.
